# Roadmap

## 0.1.x

Stabilize the V1 file/module evidence contract, adapters, path mapping, determinism, and report usability from real-world compatibility reports.

## 0.2 / 1.1

- Hardened GitHub Action and sanitized PR summary.
- Additional language graph adapters, beginning only when language-specific fixtures and resolution rules are defensible.

## Later

- Runtime trace ingestion.
- Fair agent comparison after task/session matching is defined.
- Selected symbol-level impact where compiler APIs provide strong semantics.
- Optional historical/team analytics with an explicit privacy model.

Risk-calibrated learned ranking is research-only until labeled defect datasets exist; it must not contaminate deterministic V1 semantics.
